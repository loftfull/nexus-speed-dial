# Changelog

## [2.2.0] - 2026-09-30

Светлая тема: доступный контраст, акцентные цвета, видимое выделение.

### Добавлено
- Семантические цветовые токены (`src/lib/theme.ts`): текст, приглушённый и третичный текст,
  звезда избранного, акцент. Значения записываются в CSS-переменные (`--nx-*`), Tailwind-утилиты
  `text-muted`, `text-subtle`, `bg-accent`, `text-accent-text` и др. читают их через `@theme inline`.
- Выбор акцентного цвета в настройках: Blue, Indigo, Violet, Teal, Rose, Amber (сохраняется в `prefs.accent`).
- Цветные буквенные заглушки иконок: оттенок вычисляется из домена, поэтому без сети сайты различимы.
- Заглушка превью в карточке: светлый градиент в оттенке сайта с доменом вместо повторной буквы.
- 30 тестов контраста WCAG 2.x: все текстовые токены ≥ 4.5:1 на фоне страницы, стекла карточки
  и белом; звезда ≥ 3:1 (графический элемент, WCAG 1.4.11); белый текст на каждом акценте ≥ 4.5:1;
  буквенная заглушка ≥ 4.5:1 для всех 360 оттенков.

### Исправлено
- Выделение карточек в режиме Select было невидимым: `ring-2` строится на `box-shadow`,
  который перекрывал класс `.shadow-float`. Теперь используется `outline`.
- Серый вспомогательный текст светлой темы (`text-slate-400` = `#90a1b9` в Tailwind 4) имел контраст
  около 2.6:1 к белому; заменён токеном `--nx-subtle` (`#5b6b82`).
- Звезда избранного `amber-500` (≈2.2:1 к белому) заменена на `#c26100`.
- Кнопка Paste в ночной теме: контраст 3.6:1 → добавлен тёмный вариант цвета.

### Изменено
- По умолчанию 3 колонки карточек вместо 2 (сохранённые настройки пользователя не меняются).

## [2.1.0] - 2026-09-27

Первый выпуск Navigator как самостоятельного направления внутри репозитория `nexus-speed-dial`
(код перенесён в каталог `navigator/`).

### Примечание о 2.0.0
Аудит кода 2.0.0 показал, что часть пунктов из записи 2.0.0 ниже в коде отсутствовала или
не работала: пагинация, Move to, `⌘,`, проверка `response.ok`, обработка ошибок AI 401/429,
валидация импорта, миграции схемы, исправление `visibleSites`/`activeCollection`,
режимы Icons/List/Table, тема Auto Contrast. В 2.1.0 они реализованы (см. ниже);
вид Table удалён и при загрузке заменяется на List.

### Исправлено
- Сайт, добавленный через форму, сохранялся **без `id`** — его нельзя было удалить или открыть в Info.
- Активная умная коллекция не фильтровала сетку; счётчик коллекций игнорировал правила `tags` и `project`.
- Клик по тегу не фильтровал сайты (переключал несуществующий режим `tag`).
- Пункт меню «Tile settings» не открывал никакого окна, но блокировал прокрутку страницы и скрывал док.
- Командная палитра не учитывала введённый запрос; ↑↓ не работали; вложенные `<button>` (невалидный HTML).
- Тема Night не включала `dark:`-стили Tailwind (класс `.dark` не ставился) и не меняла фон.
- Классы `chip`, `chip-blue`, `shadow-header` использовались, но не были определены в CSS.
- Кнопка Undo показывалась в любом уведомлении и могла вернуть давно удалённые сайты;
  таймер уведомления не сбрасывался и скрывал следующие уведомления раньше времени.
- Если пользователь удалял все сайты, при перезагрузке возвращались демо-сайты.
- Горячие клавиши 1–9 срабатывали при открытых окнах и с модификаторами.
- Microlink-запросы не проверяли `response.ok`; при `screenshot=true` брался `image`, а не `screenshot`.
- Ответ OpenAI читался из `output_text`, которое добавляют SDK; в сыром HTTP-ответе текст
  лежит в `output[].content[]` — теперь поддерживаются оба варианта, JSON в ```-блоке тоже.
- `extractedAt` ставится только если метаданные/AI действительно что-то заполнили.
- В шаблоне Finance заменён Mint (закрыт Intuit 23.03.2024) на Credit Karma.

### Добавлено
- Редактирование сайта (та же форма, что и добавление), дублирование.
- Виды Icons и List, плотность Compact/Comfortable, тема High contrast, `prefers-reduced-motion`.
- Фильтр по тегу, умные коллекции с правилами «проект» и «любой из тегов».
- Командная палитра: поиск по нескольким словам с ранжированием, ↑↓/↵/⇧↵.
- Массовые действия: «All», «Move to…» (пустые поля не перезаписывают значения), подтверждение удаления.
- Пагинация по 50 сайтов, раздел Recent по времени последнего открытия (`lastVisitedAt`).
- Формат данных v3 с валидацией и миграцией ключей 2.0; лимит импорта 1000 сайтов;
  бэкап перед импортом; предупреждение при переполнении `localStorage`.
- Статусы автозаполнения: успех / частичный успех / ошибка с причиной (сеть, 401, 429, HTTP, JSON).
- Индикатор места вставки при drag-and-drop; подсказки горячих клавиш 1–9 на карточках.
- Fallback иконок: своя иконка → Google favicons → первая буква.
- ARIA-роли для диалогов, меню, палитры и переключателей.
- 34 unit-теста (Vitest) для `schema`, `storage`, `filter`, `enrich`; скрипты `typecheck`, `test`;
  `build` теперь запускает проверку типов; CI в `.github/workflows/navigator.yml`.

### Изменено
- Логика вынесена из `App.tsx` в `src/lib/*`; `AddSiteModal` заменён на `SiteEditor`.
- Удалены неиспользуемые `framer-motion`, `types/sessions.ts`, настройки `automotiveMode`/`floatingCards`.
- Обновлены dev-зависимости: `vite` 7.3.2 → 7.3.6, `vitest` 5.0.2 (`npm audit`: 0 уязвимостей на 2026-09-27).

## [2.0.0] - 2024-01-15

### Добавлено

#### UI/UX
- Полная переработка дизайна с премиальным стилем
- Glassmorphism UI с backdrop-blur эффектами
- Улучшенная типографика с правильными размерами и tracking
- Keyboard shortcuts: ⌘K, ⌘,, 1-9, Esc
- Empty states с иконками и понятными сообщениями
- Confirm dialogs для удаления (одиночное и массовое)
- Keyboard shortcuts подсказка в Navigator
- Premium компоненты: PremiumCard, PremiumButton, PremiumBadge
- Мобильная адаптация с увеличенными touch-зонами

#### Функциональность
- Smart Collections с динамическими правилами
- Пагинация для больших библиотек (50 сайтов за раз)
- Массовые действия: Delete, Open, Favorite, Move
- Quick Access с топ-5 посещаемых сайтов
- AI-обогащение с четкими статусами ошибок
- Автоматическое резервное копирование
- Восстановление из backup
- Валидация импорта данных
- Undo/Redo для удалений

#### Надежность
- Версионирование схемы данных
- Миграции для старых данных
- Проверка response.ok для API запросов
- Обработка ошибок AI (401, 429, network)
- Маскировка AI ключа (type="password")
- Локальное хранение ключей

### Изменено

- Убраны все эмодзи из интерфейса
- Объединены фильтры в одну строку
- Улучшена иерархия навигации
- Переработан сайдбар с четкими разделами
- Увеличены отступы и скругления
- Улучшены тени и анимации

### Исправлено

- Исправлен баг с visibleSites и activeCollection
- Исправлен clearFilters (не сбрасывал activeCollectionId)
- Исправлен bulkMove (пустые поля перезаписывали значения)
- Исправлен extractedAt (ставился при ручном добавлении)
- Исправлен импорт (нет валидации структуры)
- Исправлены типы в types.ts
