# Changelog

Все значимые изменения в этом проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [2.0.0] - 2024-01-15

### Добавлено

#### UI/UX
- Полная переработка дизайна с премиальным стилем
- Glassmorphism UI с backdrop-blur эффектами
- Улучшенная типографика с правильными размерами и tracking
- Keyboard shortcuts: ⌘K, ⌘,, 1-9, Esc
- Empty states с иконками и понятными сообщениями
- Confirm dialogs для удаления (одиночное и массовое)
- Keyboard shortcuts подсказка в Navigator
- Premium компоненты: PremiumCard, PremiumButton, PremiumBadge
- Мобильная адаптация с увеличенными touch-зонами

#### Функциональность
- Smart Collections с динамическими правилами
- Пагинация для больших библиотек (50 сайтов за раз)
- Массовые действия: Delete, Open, Favorite, Move
- Quick Access с топ-5 посещаемых сайтов
- AI-обогащение с четкими статусами ошибок
- Автоматическое резервное копирование
- Восстановление из backup
- Валидация импорта данных
- Undo/Redo для удалений

#### Надежность
- Версионирование схемы данных
- Миграции для старых данных
- Проверка response.ok для API запросов
- Обработка ошибок AI (401, 429, network)
- Маскировка AI ключа (type="password")
- Локальное хранение ключей

### Изменено

- Убраны все эмодзи из интерфейса
- Объединены фильтры в одну строку
- Улучшена иерархия навигации
- Переработан сайдбар с четкими разделами
- Увеличены отступы и скругления
- Улучшены тени и анимации

### Исправлено

- Исправлен баг с visibleSites и activeCollection
- Исправлен clearFilters (не сбрасывал activeCollectionId)
- Исправлен bulkMove (пустые поля перезаписывали значения)
- Исправлен extractedAt (ставился при ручном добавлении)
- Исправлен импорт (нет валидации структуры)
- Исправлены типы в types.ts

## [1.0.0] - 2024-01-10

### Добавлено

- Базовый функционал менеджера закладок
- CRUD операции для сайтов
- Проекты, Категории, Группы
- Теги и фильтрация
- AI-обогащение через Microlink и OpenAI
- Экспорт/Импорт в JSON
- Разные режимы просмотра (Cards, Icons, List, Table)
- Drag-and-drop сортировка
- Темы (Light, Night, Auto Contrast)
