# Nexus Navigator

> Менеджер закладок в браузере: проекты → категории → группы, теги, умные коллекции, сессии,
> автозаполнение через Microlink и (опционально) OpenAI. Все данные хранятся локально в `localStorage`.

Версия **2.2.0**. Это самостоятельное направление репозитория `nexus-speed-dial`, независимое от
спецификации Nexus Speed Dial в `docs/superpowers/` (у него свой код, свои зависимости и свой CI).

## Быстрый старт

```bash
cd navigator
npm ci
npm run dev        # dev-сервер Vite
npm test           # unit-тесты (Vitest)
npm run build      # typecheck + сборка в один файл dist/index.html
```

`vite-plugin-singlefile` собирает приложение в один HTML-файл, который можно открыть без сервера.

## Возможности (что реально реализовано в 2.1)

| Функция | Где в коде |
|---|---|
| Иерархия Проект → Категория → Группа, фильтры в сайдбаре | `src/App.tsx`, `src/lib/filter.ts` |
| Разделы All / Favorites / Recent (Recent сортируется по времени последнего открытия) | `filterSites` |
| Фильтр по тегу (облако тегов со счётчиками) | `filterSites` |
| Умные коллекции: избранное, обогащённые, мин. визитов, проект, любые из тегов | `matchesCollection` |
| Вид: карточки / иконки / список; плотность; размер иконок; колонки | `src/components/SiteCard.tsx` |
| Добавление и **редактирование** сайта, дублирование, удаление с Undo | `SiteEditor.tsx`, `App.tsx` |
| Автозаполнение: Microlink (метаданные, иконка, скриншот) + OpenAI Responses API | `src/lib/enrich.ts` |
| Командная палитра ⌘K: поиск по названию, домену, описанию, пути и тегам; ↑↓, ↵, ⇧↵ | `CommandPalette.tsx`, `searchSites` |
| Массовые действия: выбрать всё, ★/☆, **Move to…**, открыть, удалить | `App.tsx` |
| Сессии: сохранить текущий вид и открыть все сайты разом | `App.tsx` |
| Шаблоны наборов сайтов (дубликаты URL пропускаются) | `src/data/siteTemplates.ts` |
| Постраничный вывод по 50 сайтов («Show more») | `PAGE_SIZE` в `App.tsx` |
| Темы Light / Night / High contrast, 6 акцентных цветов; `prefers-reduced-motion` | `src/lib/theme.ts`, `src/index.css` |
| Экспорт/импорт JSON с валидацией, авто-бэкап, восстановление | `src/lib/schema.ts`, `src/lib/storage.ts` |

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `⌘K` / `Ctrl+K` | Командная палитра |
| `⌘,` / `Ctrl+,` | Настройки |
| `1`–`9` | Открыть N-й сайт текущего вида (не срабатывает в полях ввода и при открытых окнах) |
| `Esc` | Закрыть окна |

## Цвета и доступность

Все цвета интерфейса задаются токенами в `src/lib/theme.ts` и попадают в CSS как переменные `--nx-*`.
Тесты `src/lib/__tests__/theme.test.ts` проверяют контраст по формуле WCAG 2.x: текст ≥ 4.5:1,
звезда избранного ≥ 3:1. Чтобы изменить цвет, правьте токен — тест покажет, если контраст упадёт ниже порога.

## Данные и формат

- Всё хранится под ключом `nexus-navigator-v3` (формат `version: 3`). Ключи версии 2.0
  (`nexus-v7-*`) автоматически переносятся при первом запуске 2.1 и не удаляются.
- Импорт принимает экспорт 2.0 (`version: 2`), 2.1 (`version: 3`) и голый массив сайтов.
  Записи без корректного `http(s)` URL пропускаются (их число показывается), повторяющиеся `id`
  переназначаются, лимит — 1000 сайтов за импорт. Перед заменой библиотеки запрашивается
  подтверждение и делается бэкап.
- Авто-бэкап пишется в `nexus-navigator-backup` (через 2 с после последнего изменения).

## Приватность и внешние сервисы

- **OpenAI API-ключ** хранится только в `localStorage` этого браузера (поле `type=password`)
  и отправляется только на `https://api.openai.com/v1/responses`. Любой скрипт на той же
  странице может прочитать `localStorage` — не используйте ключ с широкими правами.
- При автозаполнении и вставке из буфера URL сайта отправляется в `api.microlink.io`.
- Иконки по умолчанию запрашиваются у `www.google.com/s2/favicons`, превью — у `image.thum.io`.
  При ошибке загрузки показывается первая буква названия.

## Известные ограничения

1. Браузеры с блокировкой всплывающих окон обычно пропускают только первую вкладку при
   открытии сессии или нескольких выбранных сайтов — разрешите всплывающие окна для страницы.
2. Скриншоты и иконки зависят от внешних сервисов и недоступны офлайн.
3. Имя модели OpenAI задано константой `AI_MODEL` в `src/lib/enrich.ts`.
4. Сессии создаются через системный `prompt()`.
